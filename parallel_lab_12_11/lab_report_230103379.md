## Phase 1

At ten workers the lowest median was 521.51 ms at 16-byte separation. Crossing from 64 to 128 bytes reduced the median by only 4.11 ms (0.74%). The sweep did not resolve a sharp coherence boundary. The independently reported cache line was 128 bytes.

At stride 1, Karp–Flatt e(p) rose from 0.063 at two workers to 0.125 at eight, then fell to 0.112 at ten. At stride 16 it rose from 0.022 to 0.128 and then fell to 0.121. Isolation helped at two workers but gave no consistent advantage at higher counts. Process startup, interpreter work and heterogeneous cores all contribute to elapsed time here. The measurements do not isolate a cache-coherence penalty.

## Phase 2

For the fixed 1.6 million elements, ten processes cut median time from 1899.33 to 412.29 ms (4.607× speedup, 46.1% efficiency). The single-process serial fraction of 1.376% gives an Amdahl asymptote of 72.67× and a ten-worker prediction of 8.90×. This prediction assumes equal workers and ideal scaling of the parallel stage.

The incremental speedup fell from 0.489 when adding worker four to 0.106 when adding worker five, a 78.36% drop. This coincides with the four-performance-core count. The run did not track core placement, so it cannot establish the cause. Weak scaling increased work tenfold while time rose from 293.34 to 640.50 ms (45.8% efficiency). The 9.253× Gustafson estimate uses the serial share at ten workers; it is a model estimate.

## Phase 3

The copy kernel sustained 36.64 GB/s and the Python scalar kernel sustained 0.714 GFLOP/s. Their ratio gives a ridge of 0.01949 FLOP/byte. All three assumed intensities exceed that ridge, so their modeled attainable ceiling is 0.714 GFLOP/s. The naive, reordered and best blocked kernels reached 20.45%, 21.30% and 20.49% respectively. These ceilings describe the measured kernels; actual GEMM memory traffic was not instrumented.

The best blocked case was BS=64 (773.90 ms). Its three tiles occupy 96 KiB, above the generic 64 KiB L1d figure and below the reported 4 MiB L2. The fastest overall was unblocked i-k-j (744.44 ms). Contiguous access helped without the extra block-loop overhead. All ten blocked outputs exactly matched the reordered reference in this experiment.

## Phase 4

Static contiguous blocks took 4199.79 ms. Worker times ranged from 16.44 to 4074.04 ms because later items were more expensive (imbalance 2.475). Cyclic assignment spread expensive items among workers and gave the lowest measured time, 2226.44 ms (1.89× faster).

### harness.py

```python
from dataclasses import dataclass
import multiprocessing as mp
import time


@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float
    max_ms: float


def run_benchmark(fn, warmup_runs=3, timed_runs=9):
    for _ in range(warmup_runs):
        fn()
    samples = []
    for _ in range(timed_runs):
        start = time.perf_counter_ns()
        fn()
        samples.append((time.perf_counter_ns() - start) / 1e6)
    samples.sort()
    mid = timed_runs // 2
    median = (samples[mid] + samples[(timed_runs-1)//2]) / 2
    return BenchStats(samples[0], median,
                      samples[3*timed_runs//4] - samples[timed_runs//4], samples[-1])


def emit_verify_tag(task_id, student_seed, primary_metric, secondary_metric):
    hw = mp.cpu_count()
    payload = f"{task_id}|{student_seed}|{hw}|{primary_metric:.4f}|{secondary_metric:.4f}"
    h = 14695981039346656037
    for byte in payload.encode():
        h = ((h ^ byte) * 1099511628211) & 0xffffffffffffffff
    return f"VERIFY_HASH[{task_id}]: {h:016X} (P_log={hw})"

```

import argparse
import ctypes
import math
import multiprocessing as mp

clock = time.perf_counter_ns


def sysctl(key):
    proc = subprocess.run(['sysctl', '-n', key], capture_output=True, text=True)
    return proc.stdout.strip() if proc.returncode == 0 else 'unavailable'


@contextmanager
def block(size):
    mem = shared_memory.SharedMemory(create=True, size=size)
    try:
        yield mem
    finally:
        mem.close()
        mem.unlink()


def parts(n, p):
    return [(n*t//p, n*(t+1)//p) for t in range(p)]


def bench(fn, quick, stride=False):
    return run_benchmark(fn, 0 if quick else (2 if stride else 3),
                         1 if quick else (7 if stride else 9))


def join_all(target, args):
    jobs = [mp.Process(target=target, args=a) for a in args]
    for job in jobs:
        job.start()
    for job in jobs:
        job.join()
    if any(job.exitcode != 0 for job in jobs):
        raise RuntimeError('worker failed')


def fs(name, slot, n):
    with closing(shared_memory.SharedMemory(name=name)) as mem:
        arr = (ctypes.c_uint64 * (mem.size//8)).from_buffer(mem.buf)
        acc = 0
        for i in range(n):
            acc = (acc*6364136223846793005 + (i|1)) & 0xffffffffffffffff
            arr[slot] = acc
        del arr


def stage_b(bounds):
    acc = 0.
    for i in range(*bounds):
        x = (i % 997)*0.001
        for _ in range(35):
            x = math.sin(x*0.99+0.01)
        acc += x
    return acc


def copy_piece(args):
    a,b,lo,hi = args
    with closing(shared_memory.SharedMemory(name=a)) as dst, closing(shared_memory.SharedMemory(name=b)) as src:
        dst.buf[lo:hi] = src.buf[lo:hi]


def compute(n):
    a,b = 0.999999, 0.000002
    x0=x1=x2=x3=x4=x5=x6=x7=x8=x9=x10=x11=x12=x13=x14=x15=1.
    for _ in range(n):
        x0 = x0*a+b
        x1 = x1*a+b
        x2 = x2*a+b
        x3 = x3*a+b
        x4 = x4*a+b
        x5 = x5*a+b
        x6 = x6*a+b
        x7 = x7*a+b
        x8 = x8*a+b
        x9 = x9*a+b
        x10 = x10*a+b
        x11 = x11*a+b
        x12 = x12*a+b
        x13 = x13*a+b
        x14 = x14*a+b
        x15 = x15*a+b
    return x0+x1+x2+x3+x4+x5+x6+x7+x8+x9+x10+x11+x12+x13+x14+x15


def gemm(args):
    names,n,lo,hi,mode,bs = args
    with ExitStack() as stack:
        buffers = [stack.enter_context(closing(shared_memory.SharedMemory(name=k))) for k in names]
        a,b,c = [stack.enter_context(m.buf.cast('d')) for m in buffers]
        for z in range(lo*n,hi*n):
            c[z] = 0.
        if mode == 'ijk':
            for i in range(lo,hi):
                for j in range(n):
                    total = 0.
                    for k in range(n):
                        total += a[i*n+k]*b[k*n+j]
                    c[i*n+j] = total
        else:
            for ii in range(lo,hi,bs):
                for jj in range(0,n,bs):
                    for kk in range(0,n,bs):
                        for i in range(ii,min(ii+bs,hi)):
                            row = i*n
                            for k in range(kk,min(kk+bs,n)):
                                v = a[row+k]
                                base = k*n
                                for j in range(jj,min(jj+bs,n)):
                                    c[row+j] += v*b[base+j]


def schedule(t,p,n,mode,chunk,counter,times,gate):
    def item(i):
        x = 0.1
        for _ in range(1+i*i//3600):
            x = math.sqrt(2+math.sin(x)*math.cos(x))
    gate.wait()
    start = clock()
    if mode == 'dynamic':
        while True:
            with counter.get_lock():
                lo = counter.value
                counter.value += chunk
            if lo >= n:
                break
            for i in range(lo,min(lo+chunk,n)):
                item(i)
    else:
        ids = range(t,n,p) if mode == 'cyclic' else range(*parts(n,p)[t])
        for i in ids:
            item(i)
    times[t] = (clock()-start)/1e6
